# Telegram-бот «Погода»

Telegram-бот, который по названию города показывает текущую погоду. Интерфейс на русском и английском, единицы измерения и состав выводимых данных настраиваются для каждого пользователя.

Полное техническое задание приведено ниже, в разделе «Техническое задание».

## Возможности

- Погода по названию города на русском или английском языке (данные OpenWeatherMap).
- Вывод: город и страна, описание погоды, температура, ощущаемая температура, влажность, давление, скорость ветра с оценкой силы (штиль, слабый ветер, сильный ветер, шторм).
- Двуязычный интерфейс (русский и английский), язык описания погоды совпадает с языком интерфейса.
- Настройки для каждого пользователя:
  - скорость ветра в м/с или км/ч;
  - температура в °C или °F;
  - включение и отключение шести параметров в ответе (погода, температура, ощущается как, влажность, давление, ветер).
- Навигация inline-кнопками с кнопкой «Назад».
- Логирование действий пользователей в консоль.

## Команды

| Команда | Действие |
|---|---|
| `/start` | Выбор языка и переход в главное меню |
| `/weather` | Запрос погоды: бот ждёт название города |
| `/info` | Информация о боте |

## Требования

- Python 3.12 или новее (в коде используются вложенные кавычки в f-строках)
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather)
- API-ключ [OpenWeatherMap](https://openweathermap.org/api) (Current Weather Data)

Зависимости:

```bash
pip install pyTelegramBotAPI requests
```

## Установка и запуск

1. Скачайте файл с кодом бота (в примере ниже он называется `bot.py`).
2. Откройте файл и вставьте ключи в начале:

   ```python
   api_key = 'ТОКЕН_ТЕЛЕГРАМ_БОТА'
   weather_key = 'КЛЮЧ_OPENWEATHER'
   ```

3. Запустите бота:

   ```bash
   python bot.py
   ```

В консоли появится сообщение «Бот запущен», после этого бота можно открыть в Telegram и отправить `/start`.

> Не публикуйте файл с настоящими ключами в открытом репозитории. Безопаснее читать их из переменных окружения, например через `os.environ`.

## Как пользоваться

1. Отправьте `/start` и выберите язык.
2. В главном меню нажмите «Погода в городе» (или отправьте `/weather`).
3. Напишите название города, например `Лондон` или `London`.
4. Получите сообщение с погодой. Кнопка «Меню» вернёт в главное меню.

Изменить язык, единицы измерения и набор выводимых данных можно в «Настройки».

## Как это работает

Бот работает в режиме long polling (`bot.polling`). Настройки пользователей хранятся в словаре `users` по `chat_id`, ожидание названия города отслеживается множеством `waiting_city`.

Путь запроса погоды:

1. Кнопка «Погода в городе» или команда `/weather` добавляют чат в `waiting_city`.
2. Следующее текстовое сообщение обрабатывает `info()` и вызывает `send_weather()`.
3. `get_weather()` отправляет запрос к OpenWeather (метрическая система, язык интерфейса, таймаут 10 секунд).
4. При успехе (HTTP 200) `format_weather()` собирает и отправляет сообщение.
5. Если город не найден (404 или 400) или произошла сетевая ошибка, бот присылает сообщение об ошибке и снова ждёт город.

### Классификация ветра

Сила ветра определяется по скорости в м/с, независимо от выбранных единиц:

| Скорость, м/с | Оценка |
|---|---|
| до 0,2 | Штиль |
| 0,3 – 7,9 | Слабый ветер |
| 8 – 20,7 | Сильный ветер |
| больше 20,7 | Шторм |

## Известные ограничения

- Настройки хранятся в памяти и сбрасываются при перезапуске бота.
- Значения ветра между границами диапазонов (например, 0,25 или 7,95 м/с) сейчас попадают в «Шторм»: условия нужно заменить на непрерывные диапазоны.
- В сообщении для сильного ветра вместо перевода выводится `sw`: в `format_weather()` нужно использовать `lg["sw"]`.
- Два обработчика называются `cal`: работают корректно, но вторую функцию лучше переименовать.
- В английском словаре у ключей `hum` и `pres` нет двоеточия, в русском оно есть.

## Техническое задание: Telegram-бот «Погода»

Версия 1.0 · 2 ноября 2026

### 1. Общие сведения

**Наименование:** Telegram-бот для получения текущей погоды по названию города.

**Назначение:** бот принимает от пользователя название города и возвращает актуальные данные о погоде. Интерфейс двуязычный (русский и английский), состав и единицы измерения выводимых данных настраиваются каждым пользователем.

**Технологии:**

- язык программирования: Python 3.12 или новее (в коде используются вложенные кавычки в f-строках);
- библиотеки: `pyTelegramBotAPI` (`telebot`), `requests`, `logging`;
- платформа: Telegram Bot API, режим long polling;
- внешний сервис: OpenWeatherMap, Current Weather Data API (`https://api.openweathermap.org/data/2.5/weather`).

### 2. Цели и задачи

**Цель:** дать пользователю быстрый доступ к текущей погоде в любом городе мира прямо в Telegram, без регистрации и установки дополнительных приложений.

**Задачи:**

- реализовать запуск бота, выбор языка и главное меню на inline-кнопках;
- реализовать получение погоды по названию города через OpenWeather;
- реализовать пользовательские настройки: язык, единицы скорости ветра, единицы температуры, набор выводимых параметров;
- обеспечить навигацию по меню с кнопкой «Назад»;
- обработать ошибки сети и неверный ввод города;
- вести журнал действий пользователей.

### 3. Пользователи и сценарии

Пользователь бота: любой пользователь Telegram. Регистрация не требуется, идентификатором служит `chat_id`.

Основные сценарии:

1. **Запуск.** Пользователь отправляет /start, выбирает язык и попадает в главное меню.
2. **Получение погоды.** Пользователь нажимает «Погода в городе» или отправляет /weather, вводит город и получает сообщение с погодой.
3. **Настройка.** Пользователь открывает «Настройки» и меняет язык, единицы измерения или набор выводимых параметров.
4. **Справка.** Пользователь открывает «Информацию» или отправляет /info и читает описание бота.

### 4. Функциональные требования

#### 4.1. Команды

Команды регистрируются в меню Telegram через `set_my_commands`.

| Команда | Действие | Обработчик |
|---|---|---|
| /start | Сбрасывает режим ожидания города, предлагает выбрать язык | `language()` |
| /weather | Просит ввести название города и включает режим ожидания | `weather_inf()` |
| /info | Показывает информацию о боте и кнопку «Меню» | `inf()` |

#### 4.2. Главное меню

Главное меню содержит три кнопки: «Настройки», «Информация», «Погода в городе». Оно показывается после выбора языка, после изменения настроек скорости и температуры, по кнопке «Меню» и при возврате кнопкой «Назад» (если пользователь уже получил погоду). При входе в меню сбрасываются флаг `idmessage` и стек `back_to`.

#### 4.3. Выбор языка

- Доступны два языка интерфейса: русский и английский. По умолчанию используется английский.
- Язык выбирается при запуске (/start) и меняется в «Настройки → Изменить язык».
- Все тексты интерфейса хранятся в словаре `TEXT` по ключам языка и выбираются функцией `get_lg()`.
- Язык также передаётся в OpenWeather (параметр `lang`), поэтому описание погоды приходит на выбранном языке.

#### 4.4. Получение погоды

1. После нажатия кнопки «Погода в городе» или команды /weather бот добавляет `chat_id` в множество `waiting_city` и просит ввести город.
2. Следующее текстовое сообщение от пользователя обрабатывается как название города (`info()`): режим ожидания снимается, показывается статус «typing», вызывается `send_weather()`.
3. Если пользователь пишет текст вне режима ожидания (`notinfo()`), бот предлагает нажать кнопку «Погода в городе».
4. `get_weather()` отправляет GET-запрос к OpenWeather с параметрами: `q` (город), `appid` (ключ API), `units=metric`, `lang` (язык интерфейса), таймаут 10 секунд.
5. При успешном ответе (HTTP 200) данные передаются в `format_weather()` и отправляются пользователю.
6. Название города можно вводить на русском или английском языке.

#### 4.5. Формат ответа с погодой

Сообщение отправляется в режиме HTML и содержит:

- заголовок «Погода в <город>», где город написан так, как ввёл пользователь (с заглавными буквами);
- название города и код страны из ответа API;
- описание погоды;
- температуру и ощущаемую температуру;
- влажность в процентах;
- давление в гПа;
- скорость ветра в выбранных единицах и словесную оценку силы ветра.

К сообщению прикрепляется кнопка «Меню». Каждый из шести параметров (описание, температура, ощущается как, влажность, давление, ветер) можно скрыть в настройках; название города показывается всегда.

#### 4.6. Классификация силы ветра

Сила ветра определяется по скорости в м/с, полученной от API, независимо от выбранных пользователем единиц.

| Скорость, м/с | Оценка (рус.) | Оценка (англ.) |
|---|---|---|
| меньше 0,3 | Штиль | Calm |
| от 0,3 до 8 | Слабый ветер | Light wind |
| от 8 до 20,8 | Сильный ветер | Strong wind |
| 20,8 и больше | Шторм | Storm |

Границы диапазонов должны быть непрерывными, чтобы любое дробное значение попадало ровно в одну категорию.

#### 4.7. Настройки

Меню «Настройки» содержит четыре раздела.

| Раздел | Варианты | Поведение |
|---|---|---|
| Изменить язык | Русский, English | Меняет язык интерфейса, затем открывает главное меню |
| Скорость ветра | м/с (по умолчанию), км/ч | Значение в км/ч считается как м/с × 3,6 |
| Градусы | °C (по умолчанию), °F | Значение в °F считается как °C × 1,8 + 32 |
| Настройка | Шесть переключателей с отметками «вкл/выкл» | Управляет видимостью параметров в ответе |

Переключатели в разделе «Настройка»: условия погоды, температура, ощущается как, влажность, давление, скорость ветра. После каждого нажатия экран перерисовывается с новым состоянием.

#### 4.8. Навигация

- Каждый экран с кнопкой «Назад» записывает своё положение в стек `back_to`.
- Кнопка «Назад» убирает последний элемент стека и возвращает пользователя на предыдущий экран; при пустом стеке открывается главное меню.
- Кнопка «Назад» также снимает режим ожидания города.
- Если погода уже была выдана (`idmessage = True`), возврат в главное меню отправляет его новым сообщением, чтобы не затирать сообщение с погодой.

#### 4.9. Обработка ошибок

| Ситуация | Реакция бота |
|---|---|
| Сетевая ошибка, таймаут, ответ 5xx (исключение `RequestException`) | Сообщение «Ошибка, пожалуйста попробуйте позже», режим ожидания города включается снова |
| Ответ 404 или 400 (город не найден, неверный запрос) | Сообщение «Город не найден!», режим ожидания города включается снова |
| Текст вне режима ожидания | Предложение нажать кнопку «Погода в городе» |

#### 4.10. Логирование

- Журнал выводится в консоль в формате: время, уровень, сообщение.
- Записываются запуск бота и действия пользователей: команды, переходы по меню, смена настроек, введённые города, выданная погода (город и страна).
- В записях указываются имя пользователя Telegram и `chat_id`.

#### 4.11. Дополнительная функция

При получении текста «67» вне режима ожидания бот отправляет GIF-анимацию (пасхалка). Функция необязательная и может быть удалена без влияния на основной сценарий.

### 5. Данные

Настройки пользователей хранятся в словаре `users`, ключ — `chat_id`. Запись создаётся при первом обращении функцией `user_settings()`.

| Поле | Тип | Значение по умолчанию | Назначение |
|---|---|---|---|
| `lan` | строка | en | Код языка для API |
| `lang` | логический | True | True — английский, False — русский |
| `speed` | логический | True | True — м/с, False — км/ч |
| `degre` | логический | True | True — °C, False — °F |
| `idmessage` | логический | False | Погода уже выдана, главное меню нужно отправить новым сообщением |
| `back_to` | список | пустой | Стек экранов для кнопки «Назад» |
| `we_sos`, `temp_sos`, `fel_sos`, `hum_sos`, `pres_sos`, `wind_sos` | логические | True | Видимость шести параметров в ответе |
| `mess` | объект сообщения | None | Последнее сообщение, нужно для имени пользователя в журнале |

Множество `waiting_city` хранит `chat_id` пользователей, от которых бот ждёт название города.

### 6. Нефункциональные требования

- **Платформа запуска:** любой сервер или ПК с Python 3.12+ и доступом в интернет.
- **Конфигурация:** токен Telegram-бота и ключ OpenWeather не должны храниться в исходном коде открыто; их следует задавать через переменные окружения.
- **Производительность:** время ответа определяется скоростью OpenWeather; таймаут запроса — 10 секунд.
- **Надёжность:** бот работает в режиме `polling(non_stop=True)` и не должен падать при ошибке сети.
- **Хранение данных:** настройки хранятся в оперативной памяти и теряются при перезапуске бота (допустимо для версии 1.0).
- **Локализация:** все пользовательские тексты существуют в русской и английской версиях.
- **Удобство:** вся навигация выполняется inline-кнопками, ввод текста нужен только для названия города.
